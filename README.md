# House Price Prediction

## Overview
This project predicts the estimated selling price of a house using a trained machine learning model and a Streamlit web application.

## Features
- Enter the living area of a house
- Specify the number of bedrooms
- Enter the neighborhood code
- Select the overall quality and year built
- Get an estimated house selling price

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## Run Locally
1. Clone this repository.
2. Install the required packages:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run app.py`

## Disclaimer
The predicted price is a machine learning estimate, not a guaranteed market price.
